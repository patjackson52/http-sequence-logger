Every frame is the live prototype in comparison mode. All three layouts consume one engine result (http-sequence-diff 1.0, conservative-tree-v1, ported into nll-diff.js); a sample export is in samples/comparison.diff.json. Primary is blue, secondary is orange — directional roles, never verdicts. Two synthetic pairs: the Android sign-in vs its rerun on build 1.8.1 (added 401 → refresh → retry, removed prefetch, JSON field and header changes), and the handler flow vs its rerun (confirmed reorder, concurrency change, duplicate GET /auth/me left unresolved, renamed handler shown as one-sided subtrees, truncated body as unknown).

Panel sizing: entering comparison collapses the navigator below 1700 px (☰ restores it); each side is lanes × 124 px; the gutter is 56 px; the inspector stays inline at 420 px while the main area keeps ≥ 720 px, otherwise it becomes an overlay. Both sides live in one scroll container, so scrolling and expansion are synchronised by pair, not by pixel offset.

Every frame below is the live prototype (Network Log Lab.dc.html) opened in a specific state, so the mockups and the interactive build cannot drift. Desktop frames are 1440 × 1000, mobile frames 390 × 844. All data is synthetic: a demo authentication flow between “Sample App” and the “DemoAuth” SDK against public test servers; credentials appear only as [REDACTED]. The component and style specification is in Spec.dc.html.

Design decisions: the sequence diagram owns the workspace; the two client lanes sit inside one “Mobile client” band; vertical position is event order with compressed spacing and explicit gap markers, so a 10 s timeout does not push everything else off-screen. Outcome is always glyph + text + colour. Missing values read “not recorded”, never blank.
